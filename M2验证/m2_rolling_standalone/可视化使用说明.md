# M2 结果可视化

新增 `plot_results.py`：只读取一次运行保存的 `parameters.json`、`summary.json`、`periods.csv`、`trajectory.npz`，不导入建模脚本，不重新求解，不运行 AC，不读取当前 `config.py`。

输出固定为该次结果目录下的 `figure/`。完整运行画 24 个时段；短运行只画实际执行的时段，不补零。使用参数快照中的电压限值、设备映射、目标权重和功率基值。

## 一、自动绘图

在项目目录打开终端，安装增加的绘图依赖（原有依赖不变）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 main.py
```

`results_io.save_results(...)` 保存全部数值文件后调用 `save_result_figures(directory)`，后者调用独立绘图接口 `plot_results.generate_figures(directory)`。绘图层接收的只有目录路径，与优化循环没有数据对象耦合。

绘图失败时数值文件仍然保留，终端会提示错误，详情写入 `figure/plotting_error.txt`。解决依赖等问题后可直接重绘，不需要重新求解。原 `summary.json` 的 completed 仍表示模型运行完成；绘图是否完成看 `figure/plot_status.json`。

## 二、对历史结果单独绘图

```powershell
.\.venv\Scripts\python.exe -X utf8 plot_results.py --results results/run_20261026_104718_900686
```

结果直接写入 `results/run_20261026_104718_900686/figure/`，不会另建运行目录。这里是结果目录示例，换成你要分析的运行目录即可。也支持带引号的绝对路径。

指定重点节点、分辨率和格式：

```powershell
.\.venv\Scripts\python.exe -X utf8 plot_results.py --results results/run_20261026_104718_900686 --buses 6 18 25 33 --dpi 300 --formats png pdf
```

`--buses` 只影响节点曲线图；所有热图仍包含全部非根节点。默认选最高电压、最低电压、最大预测误差、最多区间漏覆盖节点，去重后补足四个。默认输出 PNG 和矢量 PDF，也支持 SVG。重复执行覆盖本脚本同名图片和分析文件，原 JSON、CSV、NPZ 不修改。

支持当前独立项目的输出格式（parameters.json 包含 network、attributes）。更早的 preliminary_run 参数格式不完整时会给出提示，不读取当前配置猜测当时参数。

在 Python 中调用：

```python
from plot_results import generate_figures
figure_dir = generate_figures('results/run_20261026_104718_900686', buses=[6, 18, 25, 33])
```

## 三、每张图看什么

| 文件前缀 | 内容 |
|---|---|
| `01_voltage_overview` | AC 和标称预测的节点-时段电压热图、AC 越限位置、逐时段越限节点数 |
| `02_voltage_prediction_vs_ac` | 重点节点的预测中心、鲁棒预测上下界、AC 执行电压与上下限 |
| `03_prediction_errors` | 预测误差热图、逐时段 MAE/RMSE、鲁棒区间覆盖率、逐节点 RMSE |
| `04_objective_comparison` | 同时段同权重的 MILP 预测目标与 AC 评价、累计值、分项惩罚 |
| `05_parameter_uncertainty_set` | 固定线路参数盒集的中心、上下界、相对不确定半径 |
| `06_uncertainty_voltage_effect` | 电压区间宽度随时间变化、AC 超出区间的距离、各不确定参数贡献 |
| `07_executed_controls` | 光伏、负荷、储能功率、储能状态及各设备无功设定 |

`figure/README.md` 是本次图表阅读说明。`plot_metrics.json` 保存带字段解释的汇总及输入 SHA256；`plot_period_metrics.csv` 保存逐时段指标，并配有同名 `.说明.md` 字段字典。

## 四、避免误读

- 当前模型的参数集合固定，未保存集合在线更新历史。图 05 展示真实的固定快照，图 06 展示固定集合经时变 H 矩阵映射出的电压区间；不能说集合在逐步收缩。
- 预测区间是线性模型对参数盒集的最坏情形范围，不是概率置信区间，不能保证 AC 一定在内。
- AC 与模型在同一执行时段对齐；t=0 使用初始化的单时段贡献，t=1～23 使用 M2 单步目标。初始化的全日计划总目标不参加逐时段对比。
- 电压幅值单位 p.u.，平方电压单位 p.u.^2。AC 目标按平方电压越限量和执行弃光功率(p.u.)重建，与 results_io.py 的权重一致；目标不额外乘 dt。
- 两种目标共用实际送入 AC 的弃光设定。当前没有独立的执行器跟踪测量，不能把它解释为控制指令与实测设备动作的误差对比。
- 只比较本次 M2 的预测与执行，不把未执行的静态初始化计划冒充 M1 的实际表现。
- 根节点没有对应鲁棒预测列，因此电压对比统一采用非根节点。负的预测平方电压不截成零，幅值图留缺口，未定义的指标输出 null/空白。
