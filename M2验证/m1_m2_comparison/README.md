# M1静态优化与M2滚动优化对比

本目录独立于原`code`和`m2_rolling`，不修改原模型。
两种方法使用相同网络、真实阻抗、设备、负荷/光伏时序、固定不确定集合、权重、限值、初始状态及求解设置，
逐时段配对执行非线性AC潮流，分别比较两套控制的实际结果、两套优化器的预测鲁棒结果。

## 参数和物理环境一致性

1. M1和M2各自从相同、未改动的原代码快照构建独立ModelData和ACPlant。
2. `shared_scenario.json`保存原参数、控制器实际使用的数值参数与矩阵、AC模型实际使用的负荷/光伏数组和真实阻抗、求解设置。
3. 比较所有数值、数组、字典结构和控制排序，任一不一致立即报错。每个滚动时段再次检查两套场景均未改变。
4. 原项目文件存在时还核对冻结副本与原文件逐字节相同；冻结目录自身始终校验SHA256。
5. 不重新随机生成线路参数，不更换另一份IEEE33数据，不修改储能位置/数量、光伏容量、负荷曲线或电压/主网限值。
6. 对原M1实际目标向量的所有变量逐列核验，确认仅电压松弛系数100、弃光系数1，其余系数0；M2使用相同权重，另检查每步目标分解与保存值一致。
7. 完整核对初始控制向量、充放电功率和开关状态、电容档位、执行前后储能能量/SOC、全部母线复电压。逐设备对照表的差值必须全为0。

一致的主要值：基准10 MVA/12.66 kV，根节点1 p.u.，24×1 h，电压范围0.93..1.05，
权重C_V=100/C_CURT=1，光伏总装机10000 kW，主网±20000 kW/±1500 kvar。
只有节点18配置储能：1000 kW充放电、2000 kWh、±600 kvar、效率0.95、SOC范围0.2..0.9、初始0.5。
第5/12/16/29条支路r/x各自±30%，其他线路参数固定。两套真实AC都使用原BRANCHES的固定值。

M1旧代码有若干用于数值建模的宽松变量界。程序用物理控制上下界计算保守区间，确认这些界不额外限制本场景静态模型的可行控制。
例如所有可行控制的支路有功绝对值上界约0.76537 p.u.，小于旧代码的5 p.u.界。
这些界及M2无上界电压松弛的区别在报告中披露，未借对比修改模型结构。

## 对比流程与必要区别

- M1保持原代码：一次求完整24时段静态鲁棒计划，其中储能有跨时段能量约束。
- M2取**同一次M1求解**的第0时段动作，独立执行相同AC，并检查初始动作、电压、E[0]和E[1]精确一致。
- M2随后23次单步优化，使用上一步AC实测电压平方、已执行控制和能量状态；不沿用预测电压。
- 每个目标时段将两种方法各自的控制送入各自AC模型，先核对外部物理环境完全相同，再分别运行PYPOWER并独立验证潮流。共24对、48次AC校验，保存输入、控制和AC电压的哈希。
- 设备动作执行后双方分别递推自身能量，不重置SOC、无参数修正、无附加动作成本，均无日末SOC回归约束。

**物理/数值参数相同不意味着优化时域相同。** M1可以联合安排全日储能，M2只优化下一时段。
这是原有两种方法的结构差异。本对比不把它隐瞒为“唯一差别是有无反馈”，也不声称隔离了反馈本身的因果效果。
目标多解时不增加额外择优项；固定单线程、Seed=0和相同容差以便复现。不同求解器版本仍可能产生不同的同目标最优动作。

## 评价口径

主要指标从**两套实际AC结果**统一计算，包括电压极值、节点时段越限数、越限幅度积分、弃光率、真实网损、
储能吞吐与日末能量、主网P/Q越限、以及相同原权重下的实际代价。

`J_AC = 100 * sum(max(V_AC² - 1.05², 0) + max(0.93² - V_AC², 0)) + sum(P_curt_pu)`。

此式严格沿用原目标权重和功率标幺单位，未额外计入网损或日末能量价值。
两种模型自己的目标值单独保存，不能直接当成共同实际运行代价。M2下一时段预测仍是线性模型结果；只有控制执行后的AC值作为本仿真的真实校验值。
完整24时段和排除共同初始时段的1..23时段均给出统计，避免分母不一致。
电压越限计数容差1e-7 p.u.，主网功率越限计数容差0.001 kW/kvar。

主网P/Q优化约束忽略网损，真实AC主网交换包含网损且由平衡节点计算。
两者均记录实际超限，不扩大限值，也不使用Q限值强制切换平衡节点而改变原场景。
线性鲁棒电压约束不构成非线性AC电压的严格保证。

预测鲁棒对比单独计算两边的名义电压、精确盒集最坏上下界、区间宽度、松弛、电压惩罚、弃光惩罚及预测目标。
**正式预测比较采用两者相同的目标时段1..23。** M2第0时段来自共同M1初始化，不能算作独立M2预测；含此时段的统计单独标注。
另将每种方法自身的预测与自身控制的AC结果对应，报告RMSE、超出预测包络的数量及经验覆盖率。
该覆盖率不是概率置信度，也不是电压合格率。所有平方电压界保留原值；若下界为负，其幅值输出为空，不截断伪造。

## 结果文件

- `summary.json` / `metrics.csv`：同一口径的完整指标与M2−M1绝对差。
- `fairness_audit.json` / `shared_scenario.json`：参数一致性及全部时段哈希证据。
- `initial_device_states.csv` / `initial_state_audit.json`：逐设备初始值、差值和完整状态哈希。
- `paired_ac_audit.json`：24对同环境AC执行记录、各自控制和真实电压来源。
- `robust_prediction_metrics.csv` / `robust_prediction_periods.csv`：预测鲁棒统计及逐时段指标。
- `four_way_voltage_comparison.csv`：同一时段同一节点的M1预测、AC(M1控制)、M2预测、AC(M2控制)并列。
- `period_comparison.csv`：两种方法逐小时真实电压、弃光、网损、主网交换和实际代价。
- `node_voltage_comparison.csv`：逐节点真实电压、预测上下界、松弛量。
- `device_comparison.csv`：逐设备动作、充放电状态、能量和档位。
- `m1_results.npz` / `m2_results.npz`：完整数值数组，可用`np.load(..., allow_pickle=False)`读取。
- `validation_details.json`：所有原M1约束与M2鲁棒残差、设备/能量、AC一致性及求解信息。
- `test_results.txt`：本次13项测试的实际执行日志。
- `figures/`：实际效果总览、电压热图、光伏弃光、储能轨迹、网损和预测误差、无功设备控制、预测鲁棒对比、各自预测与AC对照，共8组PNG/SVG。

NPZ中时段维度为24，电压幅值包含根节点33列，电压平方/预测数组只含非根节点32列；
能量为25个时段边界，单位p.u.·h；设备功率和AC支路功率数组为p.u.。
字段名带`kw/kvar`的数组及CSV已换算工程单位。控制向量列顺序见共同场景的`control_order`。
M2附加反馈/对偶数组对应23次转换；第0时段预测诊断值来自共同M1初始化。
