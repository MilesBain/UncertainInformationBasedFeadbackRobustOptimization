# 0. M2模型研究范围、基本假设及工程实现说明

## 0.1 研究目标与模型定位

本研究旨在建立基于真实电压反馈的配电网离散时间鲁棒电压控制模型，并在已有数学建模的基础上完成优化求解与潮流仿真验证。

当前研究分为三个阶段：

1. **M1：静态鲁棒电压优化模型。** 以给定时刻的负荷、光伏及线路参数不确定信息为输入，建立不考虑时间递推反馈的鲁棒电压优化模型。
2. **M2：离散时间递推鲁棒电压控制模型。** 在M1的基础上引入相邻时刻的电压递推关系，以当前时刻真实电压状态和设备控制状态为起点，计算下一时刻的设备控制决策。
3. **后续扩展模型。** 在M2经过验证后，进一步研究基于控制执行结果的模型反馈修正，包括不确定集合更新、模型误差修正及多步滚动预测控制等。

**当前M2仅用于验证离散时间递推鲁棒优化模型的数学正确性、可求解性与基本控制效果。**

因此，本阶段只构建固定线路参数不确定集合下的单步MILP模型，并将其应用于多时段逐步滚动仿真，不研究参数在线辨识、不确定集合更新和复杂预测控制。

需要区分两个概念：

- **单步优化：** 每次只优化下一时刻 \(t+1\) 的控制决策。
- **多时段滚动仿真：** 沿已有时间序列反复求解单步MILP，每次执行控制后获得真实电压反馈，再进入下一次优化。

M2属于前者的优化模型与后者的仿真机制相结合，而不是一次性求解整个时间范围的统一多时段MILP。

## 0.2 基本建模假设

为了保证M2能够以较低的实现复杂度进行测试，采用以下基本假设。

### 假设A1：配电网拓扑已知且保持不变

研究对象为辐射状配电网。网络节点、支路连接关系及设备接入位置均已知。

仿真过程中不考虑开关操作、网络重构、线路投退以及拓扑辨识问题。

因此，网络路径矩阵 \(A\) 在整个仿真过程中为固定常系数矩阵。

### 假设A2：线路参数真实值固定，但控制器无法准确获得

设真实线路参数为：

\[
\boldsymbol\theta^*=
\begin{bmatrix}
\mathbf r^*\\
\mathbf x^*
\end{bmatrix}
\]

其中 \(\mathbf r^*,\mathbf x^*\) 分别表示各支路的真实电阻、电抗。

假设：

\[
\boldsymbol\theta_t^*
=
\boldsymbol\theta^*,
\qquad \forall t
\]

即线路参数真实值在全部仿真时段内保持不变。

在仿真程序中，采用人为引入线路参数不确定性的方式构造测试环境：

- 真实潮流仿真程序使用 \(\boldsymbol\theta^*\)。
- MILP控制器不直接使用 \(\boldsymbol\theta^*\) 进行优化，而使用线路参数不确定集合 \(\mathcal U_0\)。

两者使用相同的网络拓扑。

### 假设A3：线路参数不确定集合固定

当前M2使用盒式不确定集合：

\[
\boxed{
\mathcal U_0=
\left\{
\boldsymbol\theta:
\underline{\boldsymbol\theta}
\le\boldsymbol\theta
\le\overline{\boldsymbol\theta}
\right\}
}
\]

对于所有优化时刻：

\[
\mathcal U_t=\mathcal U_0
\]

即整个滚动仿真过程中，不根据实际控制结果调整线路参数范围。

为保证测试条件具有明确含义，可以选择名义参数 \(\hat{\boldsymbol\theta}\) 和相对不确定性系数 \(\epsilon\)，构造：

\[
\begin{aligned}
\underline{\boldsymbol\theta}
&=(1-\epsilon)\hat{\boldsymbol\theta}\\
\overline{\boldsymbol\theta}
&=(1+\epsilon)\hat{\boldsymbol\theta}
\end{aligned}
\]

其中应保证线路参数上下界满足物理约束，例如正电阻、正电抗。

在验证真实参数属于不确定集合时，应检查：

\[
\boldsymbol\theta^*\in\mathcal U_0
\]

本阶段仅要求不确定集合固定且非空、有界，不研究其在线收缩或更新。

### 假设A4：负荷及光伏时间序列已知

本阶段使用已有的完整负荷与光伏时间序列进行仿真。

在第 \(t\) 次优化中，直接从数据集中提取 \(t\) 和 \(t+1\) 时刻的负荷、光伏数据，构造外部节点注入变化量：

\[
\Delta\mathbf p_t^{ex}
=
\mathbf p_{t+1}^{ex}
-
\mathbf p_t^{ex}
\]

\[
\Delta\mathbf q_t^{ex}
=
\mathbf q_{t+1}^{ex}
-
\mathbf q_t^{ex}
\]

上述变量均为**已知输入参数，而非优化决策变量**。

本阶段不引入光伏及负荷预测算法，不考虑其预测误差，也不建立相应的不确定集合。

需要注意，本假设等价于在仿真中为控制器提供下一时刻准确的外部注入信息。其目的是单独考察线路参数不确定性和电压递推控制机制，不用于证明实际预测误差条件下的控制性能。

### 假设A5：根节点为固定电压平衡节点

定义节点集合：

\[
\mathcal N_0=\{0,1,\ldots,N\}
\]

其中节点0为根节点，其余为非根节点。

假设根节点电压标幺值固定为1：

\[
V_{0,t}=1,\qquad \forall t
\]

本文采用电压幅值平方建模，因此：

\[
v_{0,t}=V_{0,t}^2=1
\]

有：

\[
\Delta v_{0,t}=0
\]

根节点作为电压参考和平衡节点，其购电或供电功率由潮流计算确定。

由于当前M2不优化根节点电压设定值，也不优化根节点本地调节设备，因此根节点不纳入优化电压状态向量及设备控制映射矩阵。

但根节点仍然参与实际潮流计算，不能从真实网络中删除。

### 假设A6：优化模型采用忽略网损的LinDistFlow近似

为保证MILP模型的线性结构，采用忽略线路功率损耗的LinDistFlow模型。

支路潮流由节点净注入线性表示：

\[
\mathbf P_t=-A\mathbf p_t
\]

\[
\mathbf Q_t=-A\mathbf q_t
\]

节点电压采用平方电压形式：

\[
\mathbf v_t
=
v_{0,t}\mathbf1+
R(\mathbf r)\mathbf p_t+
X(\mathbf x)\mathbf q_t
\]

其中：

\[
R(\mathbf r)=2A^\top\operatorname{diag}(\mathbf r)A
\]

\[
X(\mathbf x)=2A^\top\operatorname{diag}(\mathbf x)A
\]

在拓扑与线路参数保持不变的条件下，可得到离散时间递推关系：

\[
\boxed{
\mathbf v_{t+1}
=
\mathbf v_t+
R(\mathbf r)\Delta\mathbf p_t+
X(\mathbf x)\Delta\mathbf q_t
}
\]

该方程是M2控制模型的基础。

### 假设A7：暂不考虑支路潮流容量约束

本阶段不设置：

\[
|P_{k,t}|\le P_k^{max}
\]

以及线路电流、支路视在功率容量等约束。

支路潮流仅作为计算电压变化的中间状态，必要时用于结果分析。

因此，本阶段的优化可行性不代表完整交流网络的全部运行约束均得到满足。

### 假设A8：保留电压软约束及设备基本运行约束

电压约束采用松弛变量表示：

\[
\underline v-s_{i,t+1}^-
\le v_{i,t+1}
\le\overline v+s_{i,t+1}^+
\]

\[
s_{i,t+1}^+,s_{i,t+1}^-\ge0
\]

其中：

\[
\underline v=V_{\min}^2,\qquad
\overline v=V_{\max}^2
\]

模型目标仍为最小化电压越限惩罚及光伏弃光惩罚。

对于设备，保留研究稿中已定义的光伏弃光、逆变器无功、储能充放电、储能能量状态、SVG及电容器档位等基本约束。

对于具体测试网络中不存在的设备，直接删除相应变量与约束，不额外构造虚拟设备。

本阶段不引入额外设备动作惩罚、控制平滑项或复杂运行约束。

### 假设A9：真实控制结果由交流潮流仿真生成

采用真实网络参数与非线性交流潮流模型模拟设备控制执行后的电网运行状态。

设优化得到的设备控制结果为：

\[
\mathbf u_{t+1}^{opt}
\]

真实控制仿真时，将该控制结果与下一时刻的负荷、光伏数据共同代入交流潮流计算：

\[
\boxed{
\mathbf v_{t+1}^{meas}
=
\operatorname{ACPF}
\left(
\boldsymbol\theta^*,
\mathbf p_{t+1}^{ex},
\mathbf q_{t+1}^{ex},
\mathbf u_{t+1}^{opt}
\right)
}
\]

这里的 \(\operatorname{ACPF}\) 表示根据这些输入配置完整网络、调用交流潮流计算并提取非根节点电压幅值平方的过程。

实际执行时还需保证设备设定值正确写入潮流模型，并检查潮流是否收敛。

该结果作为下一时刻M2的电压初始状态，而不是采用上一次MILP中的预测电压。

### 假设A10：暂不修正电压模型及不确定集合

M2允许在每次控制后获得真实电压反馈：

\[
\mathbf v_{t+1}^{meas}
\]

但本阶段仅将其作为下一次优化的初始电压状态。

不利用该量测数据修正：

- 线路参数估计值；
- 线路参数不确定集合；
- LinDistFlow灵敏度矩阵；
- 电压预测误差模型。

因此，当前反馈机制属于**真实状态反馈下的单步滚动优化**，尚不属于参数自适应或模型学习控制。

## 0.3 统一数学变量与矩阵维度

为保证数学公式能够直接转化为代码，统一使用非根节点作为优化状态空间。

定义：

\[
\mathcal N=\{1,2,\ldots,N\}
\]

其节点排序必须与路径矩阵、设备映射矩阵和电压向量保持一致。

| 符号 | 维度 | 工程含义 |
|---|---|---|
| \(\mathbf p_t\) | \(N\times1\) | 非根节点净有功注入 |
| \(\mathbf q_t\) | \(N\times1\) | 非根节点净无功注入 |
| \(\mathbf v_t\) | \(N\times1\) | 非根节点电压幅值平方 |
| \(A\) | \(N\times N\) | 支路与节点的路径关系矩阵 |
| \(B_p,B_q\) | \(N\times n_u\) | 可控设备的有功、无功接入映射矩阵 |
| \(\mathbf u_t\) | \(n_u\times1\) | 设备控制变量向量 |
| \(\mathbf r,\mathbf x\) | \(N\times1\) | 支路电阻、电抗 |
| \(\boldsymbol\theta\) | \(2N\times1\) | 线路不确定参数 |
| \(R,X\) | \(N\times N\) | 电压与节点注入灵敏度矩阵 |
| \(H_t\) | \(N\times2N\) | 电压递推参数矩阵 |

其中，\(A_{ki}=1\) 表示支路 \(k\) 位于根节点到节点 \(i\) 的路径上，否则为0。

设备控制向量按照原研究稿定义：

\[
\mathbf u_t=
\begin{bmatrix}
\mathbf P_t^{curt}\\
\mathbf P_t^{ESS}\\
\mathbf Q_t^{PV}\\
\mathbf Q_t^{SVG}\\
\mathbf Q_t^{CB}\\
\mathbf Q_t^{ESS}
\end{bmatrix}
\]

这里 \(\mathbf P_t^{ESS}\) 表示储能净有功注入：

\[
P_{i,t}^{ESS}=P_{i,t}^{dis}-P_{i,t}^{ch}
\]

而储能充、放电功率和互斥状态可以另外设置辅助变量，不重复计入 \(\mathbf u_t\)。

如果不考虑其他类型设备：

\[
n_u=2N_{PV}+2N_{ESS}+N_{SVG}+N_{CB}
\]

对 \(B_p,B_q\)，按照设备所在节点及其有功、无功注入方向填入 \(1,-1,0\)。

例如，弃光对应有功注入减少，因此对应 \(B_p\) 中的系数为 \(-1\)。

应统一使用如下节点注入约定：

\[
\mathbf p_t=\mathbf p_t^{ex}+B_p\mathbf u_t
\]

\[
\mathbf q_t=\mathbf q_t^{ex}+B_q\mathbf u_t
\]

其中：

\[
\mathbf p_t^{ex}=\mathbf P_t^{PV,available}-\mathbf P_t^{load}
\]

\[
\mathbf q_t^{ex}=-\mathbf Q_t^{load}
\]

上述表达按不存在其他固定注入设备的简化情况定义。若测试网络中有其他不参与控制的已知注入，应并入对应外部注入向量。

所有功率、电压和阻抗必须采用一致的标幺值基准。真实潮流仿真输出的电压幅值在输入M2前必须平方。

## 0.4 单步M2的输入、变量与输出

每次优化以当前时刻 \(t\) 的真实状态为起点，计算 \(t+1\) 时刻设备控制。

### 0.4.1 已知输入

| 输入 | 来源 |
|---|---|
| \(\mathbf v_t^{meas}\) | 当前时刻交流潮流仿真结果 |
| \(\mathbf u_t^{act}\) | 当前时刻已执行设备控制状态 |
| \(\mathbf p_t^{ex},\mathbf q_t^{ex}\) | 历史时序数据 |
| \(\mathbf p_{t+1}^{ex},\mathbf q_{t+1}^{ex}\) | 已有时序数据中的下一时刻输入 |
| \(A,B_p,B_q\) | 网络及设备信息预处理 |
| \(\mathcal U_0\) | 初始化后的固定盒式集合 |
| \(E_t\) | 当前储能能量状态，若存在储能 |
| 设备参数 | 额定功率、档位、充放电效率等 |

上述输入在当前单步优化过程中均视为已知。

### 0.4.2 决策变量

主要决策变量包括：

\[
\mathbf u_{t+1},\quad
\mathbf s_{t+1}^+,\quad
\mathbf s_{t+1}^-
\]

以及储能充放电状态、电容器档位和鲁棒化所需辅助变量。

线路参数：

\[
\boldsymbol\theta\in\mathcal U_0
\]

不是外层MILP直接选择的控制变量，而是鲁棒电压约束需要考虑的不确定参数。

### 0.4.3 优化输出

单步M2至少输出：

1. 下一时刻各设备的控制决策 \(\mathbf u_{t+1}^{opt}\)。
2. 各节点电压松弛量 \(s_{i,t+1}^+,s_{i,t+1}^-\)。
3. 优化目标值及各项惩罚。
4. MILP求解状态、求解时间和最优性Gap。
5. 在固定不确定集合下各节点的最坏情况电压上下界。

其中，第5项用于检查鲁棒电压约束，不等同于真实交流潮流电压。

## 0.5 鲁棒约束的工程实现约定

M2延续原研究稿的参数分离表达：

\[
\mathbf v_{t+1}(\boldsymbol\theta)
=
\mathbf v_t^{meas}
+
H_t(\Delta\mathbf u_t)\boldsymbol\theta
\]

其中：

\[
\Delta\mathbf u_t
=
\mathbf u_{t+1}-\mathbf u_t^{act}
\]

\[
\Delta\mathbf p_t
=
\Delta\mathbf p_t^{ex}
+B_p\Delta\mathbf u_t
\]

\[
\Delta\mathbf q_t
=
\Delta\mathbf q_t^{ex}
+B_q\Delta\mathbf u_t
\]

\[
H_t=
2A^\top
\begin{bmatrix}
\operatorname{diag}(A\Delta\mathbf p_t)&
\operatorname{diag}(A\Delta\mathbf q_t)
\end{bmatrix}
\]

对于每个非根节点 \(i\)，定义：

\[
\mathbf h_{i,t}
=
H_t^\top\mathbf e_i
\]

按照原稿已经完成的推导：

\[
\boxed{
\mathbf h_{i,t}
=
\mathbf h_{i,t}^0+
K_i\Delta\mathbf u_t
}
\]

这里：

\[
\mathbf h_{i,t}^0
=
2\begin{bmatrix}
\operatorname{diag}(A\mathbf e_i)A\Delta\mathbf p_t^{ex}\\
\operatorname{diag}(A\mathbf e_i)A\Delta\mathbf q_t^{ex}
\end{bmatrix}
\]

\[
K_i=
2\begin{bmatrix}
\operatorname{diag}(A\mathbf e_i)AB_p\\
\operatorname{diag}(A\mathbf e_i)AB_q
\end{bmatrix}
\]

因此，\(\mathbf h_{i,t}\) 是关于控制决策的仿射表达。

### 鲁棒优化实现方式

为了保持与研究稿第6节的对偶化方法一致，第一版代码优先使用以下形式：

\[
F=
\begin{bmatrix}I\\-I\end{bmatrix}
\]

\[
g=
\begin{bmatrix}
\overline{\boldsymbol\theta}\\
-\underline{\boldsymbol\theta}
\end{bmatrix}
\]

对于节点 \(i\)：

\[
\begin{cases}
F^\top\boldsymbol\lambda_i^+
=\mathbf h_{i,t}\\
g^\top\boldsymbol\lambda_i^+
\le\overline v+s_{i,t+1}^+-v_{i,t}^{meas}\\
\boldsymbol\lambda_i^+\ge0
\end{cases}
\]

\[
\begin{cases}
F^\top\boldsymbol\lambda_i^-
=-\mathbf h_{i,t}\\
g^\top\boldsymbol\lambda_i^-
\le v_{i,t}^{meas}-\underline v+s_{i,t+1}^-\\
\boldsymbol\lambda_i^-\ge0
\end{cases}
\]

这样可以直接将参数不确定性转化为MILP线性约束。

对于盒式不确定集合，也可以通过绝对值辅助变量构造等价鲁棒约束，用于独立验证对偶化实现是否正确。

本阶段不需要使用在线更新的 \(F_t,g_t\)，而是在初始化后固定 \(F,g\)。

只要设备映射及剩余设备约束采用线性、整数线性形式，整个M2即可作为MILP求解。若测试系统不存在任何离散决策变量，则对应模型实际上退化为LP。

## 0.6 M2初始状态构造

M2必须从一个确定的真实电网状态开始滚动求解，因此需要：

\[
\mathbf v_0^{meas},\qquad
\mathbf u_0^{act}
\]

对于当前仿真测试，采用以下初始化方式。

**步骤1：确定初始设备状态。**

优先采用原静态鲁棒优化模型M1在第0时刻的求解结果：

\[
\mathbf u_0^{act}
=
\mathbf u_0^{M1}
\]

如M1暂时不可用，也可以直接设置一组满足设备运行约束的初始控制值。

**步骤2：读取第0时刻真实外部注入。**

\[
\mathbf p_0^{ex},\qquad\mathbf q_0^{ex}
\]

**步骤3：重构初始电网注入。**

\[
\mathbf p_0
=
\mathbf p_0^{ex}+B_p\mathbf u_0^{act}
\]

\[
\mathbf q_0
=
\mathbf q_0^{ex}+B_q\mathbf u_0^{act}
\]

并将对应设备设定正确转换为真实潮流模型中的设备参数。

**步骤4：执行交流潮流计算。**

采用真实线路参数 \(\boldsymbol\theta^*\) 进行runpf计算，获得各节点真实电压：

\[
\mathbf v_0^{meas}
=
\operatorname{ACPF}
(\boldsymbol\theta^*,
\mathbf p_0^{ex},
\mathbf q_0^{ex},
\mathbf u_0^{act})
\]

其中返回值为非根节点电压幅值平方。

储能的初始能量状态 \(E_0\) 由测试数据或预设的可行初始值确定。

至此，获得M2滚动控制所需的初始状态。

## 0.7 真实潮流仿真与单步控制执行

为了验证M2的实际控制效果，建立独立的真实交流潮流仿真模块。

优化模型与真实潮流模型分别使用以下信息：

| 内容 | M2优化器 | 真实潮流仿真器 |
|---|---|---|
| 网络拓扑 | 已知固定拓扑 | 相同固定拓扑 |
| 线路参数 | 固定盒式不确定集合 | 真实参数 \(\boldsymbol\theta^*\) |
| 当前电压 | 上一步真实反馈 | 根据实际潮流计算 |
| 负荷与光伏 | 已有时序数据 | 相同时序数据 |
| 设备动作 | MILP决策变量 | MILP结果作为实际设定 |
| 电压模型 | LinDistFlow递推 | 非线性交流潮流 |

需要保证两者采用相同的设备模型、功率符号和标幺值基准。

特别地，光伏弃光决策 \(P_{i,t+1}^{curt}\) 执行后，真实潮流模型中的光伏有功输出应为：

\[
P_{i,t+1}^{PV,op}
=
P_{i,t+1}^{PV,available}
-
P_{i,t+1}^{curt}
\]

其余设备控制也应按照对应的实际物理含义执行。

执行成功后：

\[
\mathbf u_{t+1}^{act}
=
\mathbf u_{t+1}^{opt}
\]

并记录真实电压：

\[
\mathbf v_{t+1}^{meas}
\]

若存在储能，同时更新并记录其能量状态 \(E_{t+1}\)。

上述状态共同作为下一次MILP的输入。

## 0.8 滚动仿真程序流程

设已有时间序列：

\[
t=0,1,\ldots,T
\]

采用以下计算流程。

**初始化阶段**

1. 读取网络数据、设备参数和时序数据。
2. 构建路径矩阵 \(A\) 和设备映射矩阵 \(B_p,B_q\)。
3. 设置真实线路参数及固定盒式不确定集合。
4. 确定初始控制状态 \(\mathbf u_0^{act}\)。
5. 执行初始runpf，获得 \(\mathbf v_0^{meas}\)。
6. 初始化储能状态和结果记录数组。

**滚动计算阶段**

对：

\[
t=0,1,\ldots,T-1
\]

依次执行：

1. 读取当前真实电压、设备状态和下一时刻外部注入。
2. 计算外部注入变化量 \(\Delta\mathbf p_t^{ex},\Delta\mathbf q_t^{ex}\)。
3. 构建当前时刻的单步鲁棒MILP模型M2。
4. 调用Gurobi求解，得到 \(\mathbf u_{t+1}^{opt}\)。
5. 将设备控制结果写入真实交流潮流模型。
6. 使用 \(t+1\) 时刻的负荷、光伏及真实线路参数执行runpf。
7. 得到 \(\mathbf v_{t+1}^{meas}\)，更新实际控制及储能状态。
8. 保存优化结果、真实电压、弃光量与求解信息。
9. 进入下一时刻。

对于M2，不使用上一步预测电压作为下一步电压初始值，而使用真实潮流计算得到的电压。

整个滚动过程中：

\[
\boxed{
\mathcal U_t=\mathcal U_0
}
\]

且：

\[
\boxed{
\mathbf v_t^{input}=\mathbf v_t^{meas}
}
\]

这两点构成当前M2最重要的实现约定。

## 0.9 单步模型测试与验收标准

当前M2首先验证单步鲁棒MILP能否正确求解，再扩展至多时段滚动仿真。

### 第一阶段：单步MILP数学验证

选择测试网络中的某个时刻，固定初始电压和设备状态，构建单步M2。

需要检查：

- Gurobi是否能够正常求解。
- 所有矩阵维度与变量索引是否正确。
- 设备约束是否满足。
- 鲁棒对偶化等式是否满足数值容差。
- 鲁棒电压约束是否成立。
- 光伏弃光及设备控制结果是否在允许范围内。

尤其需要独立验证：

\[
\max_{\boldsymbol\theta\in\mathcal U_0}
\mathbf h_{i,t}^{\top}\boldsymbol\theta
\le
\overline v+s_{i,t+1}^+-v_{i,t}^{meas}
\]

\[
\min_{\boldsymbol\theta\in\mathcal U_0}
\mathbf h_{i,t}^{\top}\boldsymbol\theta
\ge
\underline v-s_{i,t+1}^--v_{i,t}^{meas}
\]

确保鲁棒约束真正成立，而不是仅根据求解器返回最优状态判断正确性。

电压采用软约束，因此允许得到非零松弛量；应分别记录模型可行性与实际越限情况。

### 第二阶段：真实潮流一致性验证

将M2得到的设备控制结果代入runpf，检查：

- 交流潮流能否收敛；
- 设备设定是否正确执行；
- 真实节点电压是否合理；
- 控制前后的电压越限是否发生变化；
- 光伏弃光量是否与优化输出一致。

同时可以记录模型预测电压与真实电压之间的误差：

\[
\mathbf e_{t+1}
=
\mathbf v_{t+1}^{meas}
-
\left(
\mathbf v_t^{meas}
+
H_t(\Delta\mathbf u_t)
\hat{\boldsymbol\theta}
\right)
\]

本阶段仅记录误差用于模型精度分析，不通过该误差修正线路参数、不确定集合或优化约束。

由于M2使用近似潮流，而真实仿真使用非线性交流潮流，所以即使线路真实参数属于不确定集合，M2对近似电压的鲁棒约束也不构成对真实交流电压的严格保证。

### 第三阶段：多时段滚动验证

在单步测试完成后，将M2应用于完整的时间序列。

记录：

| 评价指标 | 目的 |
|---|---|
| 实际电压越限幅度及次数 | 检验真实控制效果 |
| 实际光伏弃光量 | 检验光伏消纳表现 |
| MILP目标函数值 | 记录优化性能 |
| 电压预测误差 | 评估线性递推模型精度 |
| MILP求解时间 | 评估计算性能 |
| 优化失败与潮流不收敛次数 | 评估仿真运行情况 |

如果开展M1与M2的对照实验，需要使其使用相同的网络、真实线路参数、负荷与光伏序列、设备配置及评价指标，避免不同测试条件影响结论。

## 0.10 工程实现边界与后续研究

当前M2的工程测试范围最终确定如下：

| 研究内容 | 当前M2处理方式 |
|---|---|
| 网络拓扑 | 已知、固定 |
| 根节点电压 | 固定为1 p.u. |
| 非根节点电压 | 平方电压建模 |
| 线路参数 | 真实值固定，但对优化器不完全已知 |
| 不确定集合 | 固定盒式集合 |
| 不确定集合修正 | 不考虑 |
| 负荷与光伏 | 使用已有完整时间序列 |
| 外部注入预测误差 | 不考虑 |
| 优化时间范围 | 单步 \(t\rightarrow t+1\) |
| 多时段测试 | 逐时刻重复单步求解 |
| 电压反馈 | 使用真实AC潮流电压 |
| 反馈模型修正 | 不考虑 |
| 支路容量约束 | 不考虑 |
| 电压软约束 | 保留 |
| 光伏弃光优化 | 保留 |
| 设备基本约束 | 保留 |
| 潮流模型 | 优化使用LinDistFlow，验证使用ACPF |
| 求解方式 | Gurobi求解LP/MILP |

本阶段不以证明滚动反馈优于其他方法为必要前提，而是首先证明：

**（1）建立的单步鲁棒MILP数学模型正确且能够求解。**

**（2）优化结果能够映射到实际电网设备并用于交流潮流仿真。**

**（3）能够通过真实电压反馈，在多个离散时刻重复执行M2。**

完成这些验证后，再继续研究如何利用控制执行结果修正模型，降低优化保守性并改善后续电压控制性能。

因此，当前M2的工程研究目标可以概括为：

> 在固定拓扑、固定盒式线路参数不确定集合及已知负荷光伏时间序列的条件下，构建基于真实电压反馈的单步鲁棒MILP电压控制模型，通过非线性交流潮流模拟控制执行结果，实现离散时间上的滚动优化，并检验模型的可求解性、递推正确性与基本控制效果。
